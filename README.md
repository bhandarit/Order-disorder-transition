# Transient Helices Govern Order-Disorder Transitions in Proteins

This includes all the processed data sets and code for generating them as well as Plot.

## Repository Structure

### 1. Simulation Setup

This folder contains:

- Simulation setup scripts 
- Input parameter files
- Necessary files required to run the simulations

These scripts were used to generate initial configuration and trajectories for the full-length Im30 protein and its fragments.

---

## 2. Analysis

This folder contains:

- Processed data generated from simulation trajectories
- Analysis scripts used to extract quantitative data
- Plotting scripts used to generate figures

The analysis was performed for:

- Full-length Im30
- H0–3 fragment
- H4–6 fragment

All codes and generated data corresponding to the figures presented in the Main Text and Supporting Information (SI) are organized in their respective folders.
